# ADR-0003 — U1-DEB open evidence bundle
Status: Accepted as DRAFT v1 (G0) · Date: 2026-11-05

**Decision.** ZIP with fixed file names (`manifest.json`, `observations.jsonl`, `findings.json`, `compatibility.json`, `knowledge-refs.json`, `privacy-report.json`, `README.txt`), canonical JSON, SHA-256 per file, schemas in `schemas/`. Replay hash excludes `generated_at`. Import: parse only these names, bounded sizes, no code execution; arbitrary vendor logs out of MVP.
**Why.** Cahier §13: reproducible, shareable, privacy-redacted, tool-independent.
**Consequences.** SHA-256 proves integrity only — manifest carries a fixed `integrity_notice`. No signature in v1 (authenticity not claimed). Schema evolves by semver; incompatible versions are refused with a message.
**Known G0 gaps.** `compatibility.json`, `knowledge-refs.json`, `privacy-report.json` schemas not written yet (G4). Example in `fixtures/synthetic/` is SYNTHETIC and not yet zipped.
