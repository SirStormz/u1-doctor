# Share a report

Your U1 stopped with an error? Tell us. It takes two minutes. U1 Doctor never sends anything by itself: you do it.

## 1. Write down four things

1. **The error code** on the printer screen (four groups of four digits: `dddd-dddd-dddd-dddd`).
2. **When**: printing, heating, changing tool, idle.
3. **What you saw**, in a few words.
4. **What U1 Doctor said**: the titles on the **Findings** screen, if you ran it.

## 2. Remove anything personal

What you post is **public forever**, even if you delete it. Remove IP addresses, e-mails, serial numbers, printer names and print file names (screenshots too).

## 3. Send it

Open a [**new Incident report**](https://github.com/SirStormz/u1-doctor/issues/new?template=incident-report.yml), fill the short form, post.

That's all. You get an answer in the issue.

**Have a capture?** Optional. On the **Report** screen, pick it and press **Export bundle**, then drag the zip into the issue. Open the zip first and check `privacy-report.json`.

Nothing is added to the project without your explicit yes.

## En français

U1 s'est arrêtée sur une erreur ? Dis-le-nous, en deux minutes. U1 Doctor n'envoie rien tout seul : c'est toi qui le fais.

1. Note **le code d'erreur** de l'écran (quatre groupes de quatre chiffres), **quand** c'est arrivé (impression, chauffe, changement d'outil, à l'arrêt), **ce que tu as vu**, et **ce que U1 Doctor a dit** (écran Constats).
2. Enlève tout ce qui est personnel : **tout ce qui est posté est public pour toujours**, même effacé. Pas d'IP, d'e-mail, de numéro de série, de nom de fichier (captures d'écran comprises).
3. Ouvre une [issue « Incident report »](https://github.com/SirStormz/u1-doctor/issues/new?template=incident-report.yml), remplis le court formulaire, envoie.

Une capture ? Facultatif : écran Rapport, choisis-la, « Exporter le paquet », glisse le zip dans l'issue. Rien n'est ajouté au projet sans ton accord explicite.
