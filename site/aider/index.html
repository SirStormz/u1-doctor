Help U1 Doctor

The rules were written from the official documentation. A real incident from a real U1 is the only way to find out where they are wrong or too weak.

Send a report

Send a report in five minutes

  1. 1

    Write down what happened

    The exact error code in the form dddd-dddd-dddd-dddd, the firmware version, when it happened and what you tried.

  2. 2

    Take a read-only capture, if you can

    Capture from the Diagnose screen, then export a bundle from the Report screen. Open the zip first and read what it lists.

  3. 3

    Check before you post

    An issue is public and stays indexed even if you delete it. Remove IP addresses, serial numbers, e-mail addresses and print file names, also from screenshots.

  4. 4

    Open the incident form

    You write it and you attach the file yourself. U1 Doctor never sends anything by itself.

What we are missing

A real failure

Every incident in the app is synthetic. One real capture would test the rules for the first time.

Rules that never fired

Rules S17 to S21 stayed quiet on a healthy print. Their positive case has never been seen on a real printer.
